# 아레나 리더보드 읽기

`omm arena --leaderboard`는 공개된 집계 파일과 서명을 확인하고 품질 티어,
효율 비교 그룹, 유효 대결 수와 둘 다 나쁨 비율을 보여준다. 실행기를 시작하거나
모델을 로드하지 않고 비공개 투표 저장소에도 접근하지 않는다.

품질 강도와 비교 구간은 로그 척도라 음수도 정상이다. 효율은 같은 품질 티어와
비교 그룹 안에서만 순서를 가른다. 서로 다른 효율 그룹 사이에 전체 순위를
만들지 않는다. 표본이 부족한 모델은 `Provisional`, 없는 측정은 `Not measured`다.

```sh
omm arena --leaderboard
omm arena --leaderboard --json
omm arena --leaderboard --offline
```

검증된 자료와 서명은 하나의 로컬 캐시로 원자적으로 저장한다. 서버에 접속하지
못하면 이전에 검증한 캐시만 다시 검증해 사용하고 캐시임을 표시한다. 캐시의
내용이 바뀌었거나 현재 공개키와 맞지 않으면 사용하지 않는다. 7일이 지난 자료는
오래됐다는 안내를 표시한다. 아직 발행된 파일도 유효한 캐시도 없다면 순위를
만들어 표시하지 않는다.

웹에서는 `/arena`와 `/en/arena`에서 같은 집계 형식을 읽는다. 검색, 효율 비교
그룹 필터, 표본 부족 표시를 제공하며 서명 검증 전에는 순위를 표시하지 않는다.
투표 수집·실행기 응답·운영 저장소·게시 워크플로의 실서비스 검증은 이 읽기
화면의 검증과 별개다.
