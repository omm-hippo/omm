# 공유 AI 연결·진단 검증 기록 (2026-10-25)

## 변경과 범위

**Implemented:** 기존 웹 작업 공간에 공유 AI 연결·진단·첫 질문 화면을 추가했다.
직원은 사내망/Tailscale 주소와 발급받은 토큰을 입력하고 모델을 직접 선택한다.
연결 확인 성공 뒤에만 설정을 저장하고, 실제 생성 응답을 받은 뒤에만 응답 확인
상태로 표시한다. 서버 관리, 모델 설치·재시작·해제, RAG 설정, 에이전트 설정은 변경하지 않는다.

주요 파일은 `src/omm/web/shared_ai.py`, `src/omm/web/server.py`,
`web-ui/src/SharedAI.jsx`, `web-ui/src/shared-ai-state.js`, `web-ui/src/shared-ai.css`다.
개인정보·사용법과 명시적 데이터 삭제 대상도 함께 갱신했다.

## 로컬 브라우저 경로

Browser plugin not available: 기존 번들에 있는 Playwright의 headless Chromium을 사용했다.
사용자 창·마우스·키보드를 조작하지 않았다. 뷰포트는 1280×900, 390×844다.

| 검사 | 결과 | 관찰 |
|---|---|---|
| 페이지 식별 | 통과 | 로컬 OMM 페이지 제목·공유 AI 화면 |
| 빈 화면·프레임워크 오류 | 통과 | 새 폼·모델·대화 화면 렌더, pageerror 없음 |
| 콘솔 | 통과 | 최종 데스크톱·모바일 보기에서 error/warning 없음 |
| 연결·토큰 | 통과 | 실제 로컬 HTTP fixture의 401 → 올바른 토큰 → 모델 목록 |
| 모델 선택 | 통과 | 자동 선택 없음, 선택 전 전송 금지, 목록과 실행 준비 구분 |
| 입력·대화 | 통과 | 합성 IME Enter는 전송 안 함, 버튼 전송 후 fixture 응답 표시 |
| 저장·새로고침 | 통과 | 주소·토큰·마지막 성공 모델 복원, 대화 제거, 외부 자동 요청 없음 |
| 오류·복구 | 통과 | 404·접속 거부의 구분된 안내, 확인 후 로컬 설정 삭제 |
| 시각 검수 | 통과 | 실제 한글 렌더 확인, 가로 넘침 없음, 연결 뒤 폼 축소 |

fixture 단계의 모델·응답은 시험 데이터다. 이 단계 자체를 실제 클러스터 추론 증거로
사용하지 않는다. 다른 탭의 하드웨어·추천 데이터는 네트워크 호출을 막은 시험 서비스로
제공했으며 해당 탭의 기능 검증을 뜻하지 않는다. 공유 AI의 로컬 API와 저장 계층은 실제 코드다.

관찰된 기존 서버 제약: 검증 브라우저를 닫거나 새로고침한 직후, 진행 중이던 위키 등의
GET 응답을 쓰는 관리 서버에서 `BrokenPipeError`가 stderr에 출력됐다. 해당 응답 쓰기
경로는 이번에 변경하지 않았다. 위의 새 공유 AI 응답·저장·복원 검사는 통과했지만,
탭 종료 때 발생하는 기존 서버 로그 정리는 별도 후속 사항이다.

## 실제 공유 맥 경로

**Physical-device-verified:** 실제 MacBook Air의 새 웹 화면 → 로컬 OMM API →
Tailscale → 실제 대표 Mac의 OMM 게이트웨이 → `mlx-community/Qwen3.5-9B-4bit`.
토큰은 이 대화에서 앞서 발급한 실제 직원 토큰을 사용했고 출력·Git에 기록하지 않았다.

- 실제 화면에서 주소·토큰 입력 → 목록 요청 200 → 모델 직접 선택 → 질문 요청 200.
- `7 × 8`에 `56` 표시. 후속 검사는 `9 × 9`에 `81` 표시.
- 응답의 모델 ID가 선택 모델과 일치해야 성공한다. 다른 모델이나 비정상 응답은
  자동 테스트에서 성공으로 표시되지 않음을 확인했다.
- 새로고침 후 주소·비공개 토큰·마지막 성공 모델 복원. 대화는 제거되고 자동 외부 호출 없음.
- 토큰은 로컬 GET 응답·브라우저 localStorage에 반환/저장되지 않음.
- 이번 개발의 의도적 실제 게이트웨이 HTTP 요청 **4회**: 목록 1회 + 짧은 생성 3회.
  앞선 연결 조사까지 포함한 이 채팅의 의도적 실제 클러스터 HTTP 요청은 **11회**다.
  `omm.run`, OMM Worker 요청은 **0회**. 재시도·부하 시험·모델 관리 요청은 하지 않았다.

## Not verified / 미검증

- 실제 Windows/Linux 직원 PC의 설치부터 첫 응답까지: 이번 환경은 macOS다.
- 실제 iPhone/Android 기기: 모바일 크기의 Chromium 화면만 검사했다.
- 실제 한국어 IME 물리 키 입력: 사용자 작업 보호를 위해 전역 키 입력하지 않았다.
- 실제 사설 HTTPS 인증서 환경: 현재 공유 서버는 Tailscale의 HTTP 게이트웨이다.
- 3대·122B 모델, 모델 품질·코딩 에이전트 작업 완주·장애 후 서버 복구: 이번 기능의 검증 범위 밖이다.
- 현재 사용자의 설치된 OMM은 변경하지 않았다. 새 배포 패키지 설치·원격 CI·릴리스는 미검증이다.
