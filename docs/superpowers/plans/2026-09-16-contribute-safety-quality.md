# Contribute 보호·한도·안내와 추천 학습 진단

사용자가 다섯 가지 개선을 모두 승인했다. 기준 main은 fb1683f이며 기존 작업 공간과
설치된 OMM 및 모델 저장소를 보존하는 별도 worktree에서 작업한다.

1. 기여 작업 전부터 있던 모델·등록·연결을 보존한다. 정상 완료, 실패, 취소,
   재시도 모두 이번 작업이 소유한 파일만 정리하며 같은 파일의 동시 작업을 막는다.
2. 실제 벤치마크 엔진을 로컬 보정 계산과 저장에 전달한다. Ollama와 LM Studio의
   보정값이 서로 바뀌지 않는 회귀 검사를 추가한다.
3. 재학습 악화를 데이터와 재현 결과로 진단한다. 기존 품질 기준을 유지하고,
   기기·엔진·모델 크기별 오차 및 부족한 측정 조합을 보고한다. 운영 추천 파일이나
   서버 설정을 직접 바꾸지 않는다.
4. contribute 실행에 선택 가능한 시간·다운로드 용량·모델 수 한도를 추가한다.
   다운로드 재시도와 부분 다운로드도 비용에 포함하고 한도 때문에 멈춘 이유를 알린다.
5. 시작 안내에 반복 작업, 공개 전송 항목, 기존 모델 보존, 선택한 한도를 설명한다.
   종료 결과에 측정·전송·보류·실패와 삭제·보존한 모델을 구분해 표시한다.

검증은 임시 OMM_HOME과 로컬 서버/대역을 사용한다. 실제 엔진·실물 기기 검증과
계약·단위 검증을 구분한다. 사용자의 컴퓨터에서 실제 기여 루프를 시작하지 않는다.
