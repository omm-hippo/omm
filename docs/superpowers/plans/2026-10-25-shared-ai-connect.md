# 공유 AI 연결·진단 구현 계획

기준: `main` 0c51a924. 승인된 범위는 기존 웹 작업 공간의 직원용 연결·진단·첫 질문이다.

1. 기존 loopback 세션·Origin·작업 헤더 검사를 재사용하는 `/api/shared-ai` 경로를 추가한다.
2. `web/shared_ai.py`에 주소 검증, 직접 HTTP 전송, 모델 목록, 비공개 설정,
   실제 질문, 최근 요청 중복 방지를 모은다. 클러스터 관리 경로는 호출하지 않는다.
3. `SharedAI.jsx`를 별도 패널로 만들고 기존 사이드바·검색에 등록한다.
   연결 뒤 설정 폼은 접고, 모델 선택과 질문창을 먼저 보여 준다.
4. 오류는 고정된 코드·해결 안내로 반환한다. 원문 서버 오류·토큰을 되돌리지 않는다.
5. `shared-ai` 설정의 명시적 데이터 삭제와 개인정보·사용법 문서를 갱신한다.
6. 실제 loopback HTTP 테스트, 프런트엔드 검사와 빌드, headless 데스크톱·모바일
   사용자 흐름, 별도 HOME의 Python 회귀 검사를 수행한다.
7. 실제 Tailscale 게이트웨이에 최소 요청으로 연결·생성을 확인한다.
   시험 서버 응답과 실제 모델 응답을 분리해서 기록한다.

서버 엔진, RAG ACL, 에이전트 설정, 설치된 사용자의 OMM, 운영 웹사이트는 변경 대상이 아니다.
기존 작업의 토큰·권한 개선과 독립된 파일을 사용한다.
