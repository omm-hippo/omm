# GUI management expansion

The local GUI must support choosing a model through the existing bilingual wiki,
then selecting an exact installable package. Search descriptions and use cases,
preserve reviewed repository relationships, and show missing packages honestly.
Connection status belongs in a secondary screen alongside runner installation;
external connectivity is checked only on explicit request. Diagnostics show safe
next steps. Comparison uses actual local generation and a versioned arithmetic
smoke pack, with three speed samples and locally persisted evidence. It is not a
general quality ranking. Runtime settings reuse verified per-model profiles,
with explicit trial/save/restore actions. File management previews external
imports and incomplete downloads before changing them. Sharing stays opt-in.

All mutating operations use authenticated, same-origin, allowlisted requests,
serialized jobs and durable results. Preserve loaded models and the user's
desktop. Validate in isolated OMM storage and an owned local runtime. Report
fixture checks separately from real inference, Windows and LM Studio checks.
Bundle the extension into existing GUI PR #434 targeting main.
