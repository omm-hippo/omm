# 설치 단계의 역할 분리

`_install_impl()`은 후보 정책 판단, 엔진 링크, registry 등록, 선택적 런타임 검증,
벤치마크, 보정, 텔레메트리와 최종 설치 결과를 담당한다.

앞선 중앙 파일 준비는 `_prepare_install_artifact()`가 담당한다.

1. 기존 파일의 출처·체크섬을 확인해 재사용하거나 새 다운로드의 공간을 검사한다.
2. `--force` 정리는 사전 검사를 통과한 뒤 실행한다.
3. 파일을 내려받고 기존 취소·용량 부족 처리를 적용한 뒤 링크에 필요한 공간을 다시 확인한다.
4. 최종 SHA-256을 확인하고 링크 가능한 파일의 체크섬과 신규 다운로드 여부를 반환한다.

용량 부족 후보를 건너뛰는 기존 경로에서만 `None`을 반환한다. 다른 예외와 정리 동작은
유지했다. 파일 보존·공간 계산은 함께 두고, 링크 복구와 런타임·벤치마크 판단은
기존 설치 함수가 계속 담당한다.
